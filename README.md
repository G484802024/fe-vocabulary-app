# FE 基础词汇学习 APP

用于学习日本基本情報技術者試験（FE）的基础 IT 词汇。题干和选项为日语，答案附简体中文解析、实际应用例子和日英中词名。每题四个选项，只能提交一次，答对得 10 分。

**在线学习** [打开 FE 基础词汇学习](https://g484802024.github.io/fe-vocabulary-app/)

## 使用方式

- **随机练习**可选 10、20、50、100 道题，也可无限练习并随时结算。
- **分类练习**提供 12 个分类。**词汇大全**可按分类浏览，按日语、英语、中文搜索，也可标记已学习。
- 答错自动进入**错题本**。可以删除错题记录，或在错题本与收藏夹中单独练习。
- **学习统计**显示累计答题、正误数量、正确率、分数、已学习词汇及已结算的练习记录。返回首页可继续未完成的练习。
- 进度保存在当前浏览器的 localStorage 中。换设备、清除站点数据或用隐私窗口时，学习记录取决于该浏览器是否还保留本地数据。
- 可在手机浏览器菜单中选择“添加到主屏幕”或“安装应用”。首次在线打开并完成缓存后，已安装的站点支持离线练习。

## 本地运行与验证

需要 Node.js 22.18 或更高版本，部署使用 Node.js 24。

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

`npm test` 检查词条数量、三语名称去重、选项生成与随机位置、答题计分、练习恢复和无限模式。浏览器测试覆盖桌面与手机视口，并用与 GitHub Pages 一致的子路径验证离线加载。Playwright 默认启动和关闭预览服务。已安装 Edge 时，也可设置环境变量 `PLAYWRIGHT_CHANNEL=msedge` 运行浏览器测试。

## 更新题库

当前共 **1,076 个词汇**，按 12 个分类存放在 [src/data](src/data/)。参考 [IPA 官方考试大纲](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html) 的范围，词条、释义和例子为本项目编写。每个文件是 UTF-8 文本。

- `# ` 开头的一行标记一个日语主题。每个主题至少放四个相关概念，保证能抽出三个同主题干扰项。
- 数据行按 **稳定 ID、日语词名、英文全称、中文词名、日语定义、中文讲解、实际例子** 的顺序，用竖线分隔。
- 同义缩写放在已有词名中。保留已发布条目的 ID，避免原有错题、收藏或未完成的练习失去关联。
- 可继续向分类文件追加条目。新增后检查三语名称、定义是否准确，尤其要确认同主题内的多个选项能被清楚区分。

```text
# 文字と符号化
ascii|ASCII|American Standard Code for Information Interchange|美国信息交换标准代码|英字や数字、制御文字などを7ビットの番号で表す規格。|ASCII 用 7 位编号表示 128 个字符和控制码。|大写 A 的 ASCII 码是十进制 65。
```

应用以词条日语名称生成题干，以词条的日语定义为正确选项，从同一主题抽取三个不同的定义并打乱顺序。分题量抽题、选项顺序和未完成练习的状态在刷新后保持一致。

## 重新部署

仓库的 **Settings → Pages → Build and deployment → Source** 设为 **GitHub Actions**。推送到 `main` 会自动运行 [部署工作流](.github/workflows/deploy.yml)，通过数据、构建及浏览器测试后发布。也可在 **Actions → Test and deploy GitHub Pages → Run workflow** 手动触发部署。查看工作流的 `github-pages` 环境输出，可找到该次部署的 HTTPS 地址。
