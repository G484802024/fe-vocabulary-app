# 情報の単位
bit|ビット|Bit|比特|二つの値のどちらかを表す情報の最小単位。|一个比特可表示 0 或 1。|开关的状态可用一个比特表示。
byte|バイト|Byte|字节|一般に8個の二進の桁をまとめた情報量の単位。|现代计算机中一个字节通常由八个比特组成。|一个无符号字节可存储 0 到 255。
nibble|ニブル|Nibble|半字节|4ビットをまとめた単位。|半字节占四个比特，正好可对应一个十六进制数字。|十六进制 A 对应四位二进制 1010。
word|ワード|Word|机器字|処理装置が一まとまりとして扱う、機種に応じた長さのデータ。|机器字是处理器自然处理的一组位，位数取决于体系结构。|在一种 32 位处理器上，一个机器字可为 32 位。
kb|キロバイト|Kilobyte|千字节|SI接頭語に従えば1,000バイトを表す単位。|按十进制定义，1 kB 等于 1,000 字节。|一份 2 kB 的文件约有 2,000 字节。
kib|キビバイト|Kibibyte|二进制千字节|1,024バイトを表す情報量の単位。|KiB 使用二进制倍数，1 KiB 等于 1,024 字节。|4 KiB 的内存页有 4,096 字节。
mb|メガバイト|Megabyte|兆字节|SI接頭語に従えば100万バイトを表す単位。|按十进制定义，1 MB 等于 100 万字节。|应用商店可用 MB 标示下载大小。
mib|メビバイト|Mebibyte|二进制兆字节|1,024キビバイトを表す情報量の単位。|1 MiB 等于 2²⁰ 字节，也等于 1,024 KiB。|工具可把 8,388,608 字节显示为 8 MiB。
gb|ギガバイト|Gigabyte|吉字节|SI接頭語に従えば10億バイトを表す単位。|按十进制定义，1 GB 等于十亿字节。|手机厂商常用 GB 标示存储容量。
gib|ギビバイト|Gibibyte|二进制吉字节|1,024メビバイトを表す情報量の単位。|1 GiB 等于 2³⁰ 字节。|系统可把约 1.07 GB 显示为 1 GiB。
tb|テラバイト|Terabyte|太字节|SI接頭語に従えば1兆バイトを表す単位。|按十进制定义，1 TB 等于一万亿字节。|大容量移动硬盘常标为 2 TB。
tib|テビバイト|Tebibyte|二进制太字节|1,024ギビバイトを表す情報量の単位。|1 TiB 等于 2⁴⁰ 字节。|磁盘工具会将十进制 1 TB 显示为约 0.91 TiB。
# 数と桁
binary|2進数|Binary Number|二进制数|0と1だけで値を表し、桁が上がるごとに重みが2倍になる数。|二进制用 0 和 1 表示数，每向左一位权重翻倍。|二进制 10 表示十进制的 2。
octal|8進数|Octal Number|八进制数|0から7までの数字を使い、桁の重みが8の累乗になる数。|八进制用 0 到 7，每一位对应一个 8 的幂。|八进制 10 表示十进制的 8。
decimal|10進数|Decimal Number|十进制数|0から9までの数字を使い、桁の重みが10の累乗になる数。|十进制是日常常用的计数方式。|十进制 42 表示 4 个十和 2 个一。
hex|16進数|Hexadecimal Number|十六进制数|0から9とAからFを使って値を表す数。|十六进制用 16 种符号，每个数字可对应四个二进制位。|网页颜色 #FF0000 表示红色。
radix|基数|Radix|基数|位取り記数法で、一つの桁が取り得る数字の種類数。|基数决定一个进制有多少种数字。|二进制的基数为 2。
place-value|桁の重み|Place Value|位权|位取り記数法で、桁の位置が値に与える倍率。|位权是某个位置上单个单位代表的值。|十进制百位的位权为 100。
msb|最上位ビット（MSB）|Most Significant Bit|最高有效位|ビット列で、通常最も大きい桁の重みを持つ位置。|最高有效位通常位于二进制书写的最左侧。|写成 1001 时，左端的 1 是最高有效位。
lsb|最下位ビット（LSB）|Least Significant Bit|最低有效位|ビット列で、整数表記なら重みが1である位置。|最低有效位表示个位，可用来判断二进制整数的奇偶。|1011 的最右位是 1，所以它是奇数。
fraction|小数部|Fractional Part|小数部分|位取り記数で小数点より右側が表す部分。|小数点右侧表示不足一个整数单位的量。|二进制 10.1 的小数部分是十进制 0.5。
leading-zero|先頭のゼロ|Leading Zero|前导零|数の値を変えず、表記の左側に付く0。|对按同一进制解释的数值，在左边补零不改变它的大小。|把 7 格式化为编号 007。
# 数値表現と誤差
signed|符号付き整数|Signed Integer|有符号整数|正の値、零、負の値を扱える整数型。|有符号整数可表示负数、零和正数。|银行程序可用它表示正负金额差。
unsigned|符号なし整数|Unsigned Integer|无符号整数|零と正の値を表し、負の値を持たない整数型。|无符号整数把数值范围用于零和正数。|像素通道值可用无符号字节表示 0～255。
twos-complement|2の補数|Two's Complement|二进制补码|固定ビット長で、全ビットを反転して1を加えると符号が反転する表現。|二进制补码是计算机常用的有符号整数编码。|8 位补码中的 11111111 表示 −1。
ones-complement|1の補数|One's Complement|二进制反码|固定ビット長で、全ビットを反転して得られる値。|二进制反码把每位 0 和 1 互换。|四位的 0101 取反后得到 1010。
fixed-point|固定小数点数|Fixed-Point Number|定点数|小数点の位置をあらかじめ決めて扱う数値表現。|定点数按固定比例解释存储的整数。|把 1234 解释为金额 12.34 元。
floating-point|浮動小数点数|Floating-Point Number|浮点数|有効な桁と指数を分け、広い範囲の実数を近似する表現。|浮点数用有效数字和指数表示数值，部分小数会产生近似。|科学计算可同时处理极大和极小的量。
significand|仮数部|Significand|有效数部分|指数形式の数値表現で、値の有効な桁を担う部分。|有效数部分记录浮点数的有效数字。|在 1.23×10⁴ 中，1.23 是有效数。
exponent|指数部|Exponent Field|指数部分|浮動形式で、有効な桁を基数の何乗で拡大・縮小するかを決める部分。|指数决定有效数要按基数的多少次幂缩放。|在 1.23×10⁴ 中，指数是 4。
overflow|オーバーフロー|Overflow|溢出|計算結果が、その形式で扱える範囲を大きさの側で超えること。|数值超出类型或格式能表示的范围时会发生溢出。|把大于 255 的数放进一个无符号字节。
underflow|アンダーフロー|Underflow|下溢|浮動形式で、零でない結果の大きさが通常の表現範囲の下限を下回ること。|浮点结果太接近零时可能被表示成次正规数或零。|持续乘以很小的比例，结果最终可能变成 0。
roundoff|丸め誤差|Round-off Error|舍入误差|値を表現可能な桁数に収める際に生じる差。|舍入误差是有限精度近似带来的数值偏差。|把 1/3 保留两位小数会得到 0.33。
cancellation|桁落ち|Catastrophic Cancellation|有效数字损失|近い値の差を求める際、上位桁が打ち消されて有効な桁が減る現象。|两个很接近的近似数相减时，结果的相对误差可能变大。|两个传感器读数相减时，尾部误差可能占差值很大比例。
# 論理とビット演算
boolean|ブール値|Boolean Value|布尔值|真または偽のいずれかを表す値。|布尔值只有真和假两种状态。|记录用户是否已经登录。
and|論理積（AND）|Logical Conjunction|逻辑与|二つの条件がどちらも真の場合にだけ真になる演算。|逻辑与要求所有参与条件都为真。|账号有效且密码正确时允许登录。
or|論理和（OR）|Logical Disjunction|逻辑或|二つの条件の少なくとも一方が真なら真になる演算。|逻辑或只要求至少有一个条件为真。|用户是管理员或文档所有者时允许修改。
not|論理否定（NOT）|Logical Negation|逻辑非|真を偽に、偽を真に反転する演算。|逻辑非把条件结果反过来。|用“未登录”决定是否显示登录按钮。
xor|排他的論理和（XOR）|Exclusive OR|异或|二つの入力が異なるときにだけ真になる演算。|两项取值不同，异或结果才为真。|检测两个开关是否处在不同状态。
nand|否定論理積（NAND）|Not AND|与非|二つの入力が両方真のときだけ偽になる演算。|与非先做逻辑与，再反转结果。|用与非门组合成其他数字逻辑门。
nor|否定論理和（NOR）|Not OR|或非|二つの入力が両方偽のときだけ真になる演算。|或非先做逻辑或，再反转结果。|两个告警信号都未触发时输出真。
xnor|否定排他的論理和（XNOR）|Exclusive NOR|同或|二つの入力が同じ値のときにだけ真になる演算。|同或用于比较两个布尔值是否相同。|比较两个设备的开关状态是否一致。
truth-table|真理値表|Truth Table|真值表|入力の全組合せとそれぞれの出力を並べた表。|真值表枚举逻辑运算所有可能的输入和结果。|列出逻辑与的四组输入及输出。
bitmask|ビットマスク|Bitmask|位掩码|選択した位置のビットだけを検査・変更するためのビット列。|位掩码通过一组特定位来读取或更改状态。|只检查权限字段中的读权限位。
logical-shift|論理シフト|Logical Shift|逻辑移位|ビット列を左右にずらし、空いた位置を0で埋める演算。|逻辑移位将位向左或右移动，并在空位补零。|将一个字节的低四位移动到高四位。
arithmetic-shift|算術シフト|Arithmetic Shift|算术移位|符号付きの値を扱い、右にずらす際に符号のビットで空きを埋める演算。|算术右移用符号位填补高位。|让补码负数右移时仍保留负号。
# 文字と符号化
character-set|文字集合|Character Set|字符集|利用する文字を集めたもので、バイトへの具体的な変換方法とは別の概念。|字符集确定有哪些字符可使用或被编号。|应用选择支持日文和拉丁字母。
code-point|符号位置|Code Point|码位|符号化された文字集合で各要素に割り当てられる番号。|码位是字符集合中的编号。|Unicode 用 U+0041 标识字母 A。
encoding|文字エンコーディング|Character Encoding|字符编码|文字に対応する番号などを、保存や送信に使うバイト列に変換する方式。|字符编码规定文本怎样转换成字节及怎样还原。|按 UTF-8 读取文本文件。
ascii|ASCII|American Standard Code for Information Interchange|美国信息交换标准代码|英字や数字、制御文字などを7ビットの番号で表す規格。|ASCII 用 7 位编号表示 128 个字符和控制码。|大写 A 的 ASCII 码是十进制 65。
unicode|Unicode|Unicode Standard|统一码|世界の多様な文字や記号に共通の番号を割り当てる国際的な規格。|Unicode 为多种文字、标点和符号分配码位。|一个文本可以同时包含中文、日文和英文。
utf8|UTF-8|Unicode Transformation Format, 8-bit|UTF-8 编码|Unicodeの値を1～4バイトで表し、ASCIIの範囲では同じ1バイトを使う方式。|UTF-8 兼容 ASCII 的字节表示，其他字符可占多个字节。|用 UTF-8 保存含日文的网页。
utf16|UTF-16|Unicode Transformation Format, 16-bit|UTF-16 编码|Unicodeの値を16ビット単位一つまたは二つで表す方式。|UTF-16 的编码单元是 16 位，部分字符需要两个单元。|用两个编码单元表示某些表情符号。
shift-jis|Shift_JIS|Shift Japanese Industrial Standards|Shift_JIS 日文编码|日本語の文字を1バイトまたは2バイトで表す従来の符号化方式。|Shift_JIS 是旧式日文文本常见的多字节编码。|打开旧版日文系统导出的文本。
euc-jp|EUC-JP|Extended Unix Code for Japanese|日文扩展 Unix 编码|UNIX系で使われてきた、日本語の複数の文字集合を含む符号化方式。|EUC-JP 曾用于日文 Unix 环境。|维护旧日文 Unix 应用的文本资源。
mojibake|文字化け|Mojibake|乱码|データを作成時と異なる文字の変換規則で読み、意図しない表示になる現象。|读取编码与实际编码不匹配时，可能出现乱码。|用 UTF-8 打开 Shift_JIS 文件时日文显示异常。
bom|バイト順マーク（BOM）|Byte Order Mark|字节顺序标记|Unicodeのテキストの先頭に置き、UTF-16などの並び順の手掛かりにできる印。|BOM 是文件开头的特定标记，可用于判断 UTF-16 字节顺序。|编辑器通过开头标记区分 UTF-16 大端和小端。
line-feed|改行（LF）|Line Feed|换行符|テキストで行を次に進めることを表す制御文字。|LF 是一种换行控制字符。|许多 Unix 文本文件用 LF 分隔各行。
carriage-return|復帰（CR）|Carriage Return|回车符|もともと印字位置を行の先頭へ戻すことを表す制御文字。|CR 源于回到本行开头的控制指令。|Windows 文本常把 CR 和 LF 连用表示换行。
# 画像と色
pixel|画素|Pixel|像素|格子状のデジタル画像を構成する一つ一つの点。|像素是位图中可单独记录颜色的点。|1920×1080 表示横向和纵向的像素数。
raster|ラスタ画像|Raster Image|位图|色を持つ点を格子状に並べて表す画像。|位图把每个位置的像素颜色记录下来。|手机拍摄的照片是位图。
vector|ベクタ画像|Vector Image|矢量图|線や曲線などの形状を座標と数学的な記述で表す画像。|矢量图以几何形状保存图像，可在不同尺寸重绘。|印刷和网页使用同一个可缩放徽标。
resolution|画像解像度|Image Resolution|图像分辨率|画像の細かさを、縦横の画素数や単位長さ当たりの画素数で表したもの。|分辨率可以指图像像素尺寸或一定长度内的像素密度。|选择高像素尺寸的照片用于大幅输出。
color-depth|色深度|Color Depth|色深|画素の色を記録するために用いるビット数。|色深表示描述颜色时可用的位数。|24 位 RGB 通常给每个通道分配 8 位。
rgb|RGB|Red, Green, Blue|红绿蓝色彩模型|赤・緑・青の光の強さを組み合わせる色の表し方。|RGB 通过调节红、绿、蓝三种光的强度表示颜色。|显示器用 RGB 形成屏幕颜色。
cmyk|CMYK|Cyan, Magenta, Yellow, Key (Black)|青品黄黑色彩模型|シアン、マゼンタ、黄、黒のインク量で色を表す方式。|CMYK 使用青、品红、黄和黑四色油墨描述印刷颜色。|印刷店把宣传册图像转换为 CMYK。
grayscale|グレースケール|Grayscale|灰度|色相を持たず、黒から白までの明るさの段階だけで表す方式。|灰度图只记录由黑到白的亮度层次。|把彩色扫描件转换为灰度文件。
alpha|アルファチャネル|Alpha Channel|透明度通道|画像で色とは別に、画素の不透明度を持たせる成分。|透明度通道控制各像素覆盖背景的程度。|让徽标四周透明，以便显示底色。
aspect|アスペクト比|Aspect Ratio|宽高比|画像や画面の横と縦の長さの比。|宽高比描述画面形状，与具体尺寸无关。|16:9 视频在窄屏上可能出现黑边。
antialias|アンチエイリアシング|Anti-aliasing|抗锯齿|境界付近の画素の色を調整し、斜線などのぎざぎざを目立ちにくくする処理。|抗锯齿通过调整边缘像素，使斜线和曲线视觉上更平滑。|文字渲染时给边缘像素使用中间色。
# 音声・動画とデータ形式
sampling|標本化|Sampling|采样|連続する信号から、一定の時間間隔などで値を取り出す処理。|采样在若干时刻读取连续信号的值。|录音时每秒读取声音电信号 44,100 次。
sample-rate|サンプリング周波数|Sampling Rate|采样率|信号の値を1秒当たり何回取り出すかを表す量。|采样率用每秒采样次数衡量。|音频设备以 48 kHz 采样。
quantization|量子化|Quantization|量化|取り出した連続的な値を、有限個の段階のいずれかに割り当てる処理。|量化将测得的数值映射到有限个可表示的等级。|将声音幅度映射为 16 位整数。
bit-rate|ビットレート|Bit Rate|比特率|1秒当たりに扱うデータのビット数。|比特率表示单位时间的数据量。|视频平台根据连接速度调整视频比特率。
pcm|PCM|Pulse-Code Modulation|脉冲编码调制|信号の値を一定間隔で測り、段階化した値を符号で表す方式。|PCM 用采样值的编码来记录模拟信号。|常见的未压缩 WAV 音频保存 PCM 样本。
frame-rate|フレームレート|Frame Rate|帧率|動画や画面を構成する静止画の1秒当たりの枚数。|帧率衡量视频一秒内呈现多少幅画面。|用 60 fps 拍摄快速移动的物体。
codec|コーデック|Codec|编解码器|音声や映像を一定の形式に変換し、再生時に逆の変換を行う仕組み。|编解码器负责编码和解码媒体数据。|播放器使用 H.264 解码视频轨道。
container|メディアコンテナ|Media Container|媒体容器格式|映像、音声、字幕などを一つのファイルにまとめる形式。|媒体容器把多条媒体轨道打包在同一个文件里。|MP4 文件可同时包含视频轨道和音频轨道。
lossless|可逆圧縮|Lossless Compression|无损压缩|展開すると元のデータと完全に一致する圧縮。|无损压缩解压后可逐位恢复原数据。|用 ZIP 压缩源代码目录。
lossy|非可逆圧縮|Lossy Compression|有损压缩|一部の情報を省き、展開しても元のデータに完全には戻らない圧縮。|有损压缩舍弃部分细节来缩小文件。|调低照片质量以减少 JPEG 文件大小。
png|PNG|Portable Network Graphics|PNG 图像格式|可逆圧縮を用い、透明度も記録できる静止画像形式。|PNG 适合保留清晰边缘，也支持透明背景。|网页使用 PNG 保存透明图标。
jpeg|JPEG|Joint Photographic Experts Group (image coding standard)|JPEG 图像格式|写真などによく用いられ、通常は非可逆圧縮を使う静止画像形式。|常见的 JPEG 编码有损，适合压缩自然照片。|相机把照片保存成较小的 JPG 文件。
gif|GIF|Graphics Interchange Format|GIF 图像格式|各画像で最大256色の色表を使え、複数画像による動きも記録できる形式。|GIF 支持索引色和简单动画。|聊天应用用 GIF 显示循环动图。
svg|SVG|Scalable Vector Graphics|可缩放矢量图形|XMLを用いて形状や線などを記述するベクタ画像形式。|SVG 用文本描述矢量图形，适合图标和示意图。|同一个 SVG 图标用于不同像素密度的屏幕。
