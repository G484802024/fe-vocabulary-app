# 情報資産とセキュリティの性質
confidentiality|機密性|Confidentiality|机密性|情報を許可された人やシステムだけが利用できる性質。|保证只有经过授权的人或系统能够获取信息。|只有人事人员可以读取员工薪资表。
integrity|完全性|Integrity|完整性|情報が不正に変更されず、正確で完全な状態が保たれる性質。|保证数据未经未授权修改，并保持正确和完整。|核对软件安装包的摘要，确认文件与发布版本一致。
availability|可用性|Availability|可用性|許可された利用者が必要なときに情報やサービスを使える性質。|需要使用服务时，授权用户能够正常访问。|一个节点故障后，另一个节点继续提供查询服务。
authenticity|真正性|Authenticity|真实性|利用者や情報の発信元が主張どおりのものであると確かめられる性質。|能够确认参与者或信息来源确实是所声称的身份。|读者验证公告的签名以确认来源。
nonrepudiation|否認防止|Non-Repudiation|不可否认性|取引や操作の証拠を残し、関係者が後で行為を否定することを困難にする性質。|用可信证据帮助证明某人曾参与某个操作或交易。|保留带签名的电子合同和可信时间记录。
accountability|責任追跡性|Accountability|可追责性|実施された操作を特定の利用者や主体までたどれる性質。|能把操作与具体责任主体联系起来。|审计人员用具名账号的操作日志追溯配置变更。
information-asset|情報資産|Information Asset|信息资产|組織にとって価値があり、保護や管理の対象となる情報や関連資源。|对组织具有价值并需要保护的信息及相关资源。|客户名册被列入公司的信息资产清单。
classification|情報分類|Information Classification|信息分类|情報の重要度や公開範囲に応じて区分し、扱い方を決めること。|按敏感性和业务价值分级，并规定相应的处理方式。|把公开手册标为公开，把合同标为内部资料。
data-masking|データマスキング|Data Masking|数据脱敏|データのうち見せる必要のない部分を伏せ字や代替値などで隠す処理。|隐藏或替换不应展示的敏感字段，同时保留业务所需信息。|客服界面只显示银行卡号的后四位。
data-minimization|データ最小化|Data Minimization|数据最小化|目的の達成に必要な範囲に、個人データの収集や利用を限定する原則。|只收集和处理完成特定目的所必需的个人数据。|订阅新闻只填写邮箱，表单不询问家庭地址。
# リスクと組織の管理
threat|脅威|Threat|威胁|情報資産に損害を与える可能性がある原因や出来事。|可能危害信息或系统的因素，包括攻击、故障和灾害。|机房洪水是服务器的物理威胁。
vulnerability|脆弱性|Vulnerability|漏洞或弱点|脅威によって悪用される可能性があるシステムや運用上の弱点。|可能被威胁利用的技术缺陷或管理弱点。|审计发现老旧设备缺少供应商的安全更新。
security-risk|情報セキュリティリスク|Information Security Risk|信息安全风险|情報資産への悪影響について、発生の可能性と影響を考慮したもの。|综合考虑安全事件发生的可能性及其后果。|评估重要文件误共享给外部人员的可能性和损失。
risk-assessment|リスクアセスメント|Risk Assessment|风险评估|危険の要因を特定・分析し、対応の必要性や優先度を評価すること。|识别、分析和评价风险，决定优先处理哪些。|列出客户资料面临的风险，再按影响和可能性排序。
risk-avoidance|リスク回避|Risk Avoidance|风险规避|危険の原因となる活動を取りやめ、対象の危険を生じさせない対処。|通过停止或不开展某项活动避开其风险。|停止提供不再维护且风险较高的旧外部服务。
risk-reduction|リスク低減|Risk Mitigation|风险降低|対策を施し、望ましくない出来事の可能性や影響を小さくする対処。|用控制措施降低事件发生概率或损害程度。|为员工账号增加多因素认证以减少账户盗用风险。
risk-transfer|リスク移転|Risk Transfer|风险转移|契約や保険を利用して、危険による損失の一部を他者が負担するようにする対処。|通过保险或合同安排分担部分风险后果。|公司购买保险承担某些安全事故的部分经济损失。
risk-acceptance|リスク受容|Risk Acceptance|风险接受|対処の要否を検討した結果、残る危険を組織が了解して引き受けること。|确认剩余风险在可接受范围内并记录接受决定。|负责人记录某低影响内部页面的残余风险并批准上线。
security-policy|情報セキュリティポリシー|Information Security Policy|信息安全方针|情報資産を守るための基本方針、責任や対策の方向を定めたもの。|明确组织保护信息资产的原则、职责和措施方向。|企业规定涉密文件的共享范围及审批责任。
isms|ISMS|Information Security Management System|信息安全管理体系|情報資産の保護を組織全体で計画し、実施・評価・改善するための管理の仕組み。|让组织持续识别风险、实施措施并检查和改进。|公司定期复查安全目标和制度的执行情况。
# 本人確認と権限管理
identification|識別|Identification|身份标识|名前や番号などを使い、どの利用者や主体かを区別する処理。|用标识符表明主体是谁。|登录时先输入员工编号来表明身份。
authentication|認証|Authentication|身份认证|提示された情報や証拠を検証して、主張された本人や主体であることを確かめる処理。|验证一个用户或系统确实拥有所声称的身份。|系统校验登录人提交的密码。
authorization|認可|Authorization|授权|本人確認などを経た主体に、特定の資源や操作を許してよいかを決める処理。|按规则决定用户能访问哪些资源、执行哪些操作。|系统允许财务人员编辑报销单，普通员工只能提交。
mfa|多要素認証（MFA）|Multi-Factor Authentication|多因素认证|知識・所持・生体など、異なる種類の証拠を二つ以上組み合わせて本人を確認する方式。|用至少两种不同类别的因素证明身份。|输入密码后，再在登记的手机上确认登录。
otp|ワンタイムパスワード（OTP）|One-Time Password|一次性密码|一回の認証だけで有効になるように発行される使い捨てのパスワード。|只能成功使用一次的密码，通常有有效期。|验证应用产生短时间有效的动态验证码。
biometric|生体認証|Biometric Authentication|生物特征认证|指紋や顔など、本人の身体的・行動的な特徴を利用する認証方式。|通过人的生理或行为特征确认身份。|手机用指纹匹配验证解锁者。
sso|シングルサインオン（SSO）|Single Sign-On|单点登录|最初に本人を確認した後、その結果を利用して複数のサービスに入れる仕組み。|登录一次后，可在受信任的多个服务使用相同的身份会话。|员工登录公司门户后直接进入内部日历。
rbac|ロールベースアクセス制御（RBAC）|Role-Based Access Control|基于角色的访问控制|役職や業務上の役割に権限を付与し、利用者に役割を割り当てる方式。|把权限绑定到角色，再把角色分配给用户。|给审核员角色授予审批权限。
acl|アクセス制御リスト（ACL）|Access Control List|访问控制列表|資源に対して、誰がどの操作を許可または拒否されるかを並べた一覧。|用条目记录哪些主体可以访问资源及可执行哪些操作。|共享目录规定编辑组可写入、其他员工只读。
least-privilege|最小権限の原則|Principle of Least Privilege|最小权限原则|利用者やプログラムに、担当する作業に必要な最小限の権限だけを与える原則。|每个用户和程序只应得到完成工作所需的权限。|用于生成报表的服务账号只有读取权限。
# 暗号・ハッシュ・署名
encryption|暗号化|Encryption|加密|鍵などを使い、元のデータをそのままでは読めない形式へ変換する処理。|把明文转换成密文，阻止未获授权的人读取内容。|备份文件加密后才存放在外部存储上。
decryption|復号|Decryption|解密|適切な鍵などを使い、保護されたデータを元の読み取れる形に戻す処理。|使用相应的密钥将密文恢复为明文。|恢复备份时，管理员使用正确密钥读取文件。
symmetric|共通鍵暗号方式|Symmetric-Key Cryptography|对称密钥密码|データを保護する処理と元に戻す処理で、送受信者が同じ秘密鍵を用いる方式。|加密和解密使用同一个共享秘密密钥。|压缩归档使用一个对称密钥加密和恢复数据。
asymmetric|公開鍵暗号方式|Public-Key Cryptography|公钥密码|公開できる鍵と本人だけが管理する鍵を対にして使う方式。|使用一对数学关联的公钥和私钥。|发送者可使用接收者公钥保护小段密钥材料。
public-key|公開鍵|Public Key|公钥|鍵の対のうち、他の人に配布して署名の検証などに使わせる側の鍵。|可以分发给他人的一端密钥，可用于验签或加密。|用户下载发布者公钥核验软件签名。
private-key|秘密鍵（公開鍵暗号）|Private Key|私钥|鍵の対のうち、所有者が外部に公開せず署名生成などに使う側の鍵。|密钥对中应由所有者严格保密的一端，可用于签名或解密。|公司用只保存在安全设备中的私钥签署发布包。
hash|暗号学的ハッシュ関数|Cryptographic Hash Function|密码学哈希函数|入力から固定長の値を求め、そこから入力を逆算したり同じ値の別入力を探したりしにくい関数。|把任意长度数据变成固定长度摘要，并让逆推输入或构造碰撞很困难。|比较下载文件的 SHA-256 摘要和网站公布的值。
salt|ソルト|Password Salt|密码盐值|パスワードを要約する前に、同じパスワードでも結果が異なり得るよう付け加える値。|给每条密码记录使用独立随机值，避免相同密码得到相同摘要。|两名用户使用相同密码时，数据库中的密码哈希仍不同。
digital-signature|デジタル署名|Digital Signature|数字签名|文書に対応する検証用の値を秘密鍵で作り、公開鍵で発信元や改変の有無を確認する仕組み。|签署方用私钥生成签名，接收方用公钥验证签名及内容完整性。|用户验证软件包是否由指定发布者签署。
hmac|HMAC|Hash-based Message Authentication Code|基于哈希的消息认证码|共有した秘密鍵とハッシュ関数を使って、メッセージの改変などを検出する検証値。|用共享密钥和哈希函数生成验证值，验证消息完整性和持钥方身份。|服务接收通知时核对通知正文和认证码是否一致。
# 暗号化通信と証明書
aes|AES|Advanced Encryption Standard|高级加密标准|128ビットのブロックを処理し、128・192・256ビットの鍵を使える共通鍵暗号規格。|常见的对称分组密码标准，支持三种密钥长度。|磁盘加密系统使用这一标准保护磁盘数据。
rsa|RSA|RSA Public-Key Cryptosystem|RSA 公钥密码体制|大きな合成数の素因数分解の難しさを背景とする公開鍵暗号方式。|基于大整数分解困难性的公钥密码方案，可配合适当填充用于加密或签名。|系统使用 RSA 签名验证受信任机构发布的文件。
tls|TLS|Transport Layer Security|传输层安全协议|通信相手の認証、暗号化、改変検出などで通信路を保護するプロトコル。|保护数据传输，通常验证服务器身份并加密通信。|用户登录网页时，用该协议保护发送的登录信息。
digital-certificate|デジタル証明書|Digital Certificate|数字证书|公開鍵と利用者・組織・ドメイン名などとの結び付きについて発行者が署名した電子文書。|由签发者签名，证明一个公钥与特定主体或域名相对应。|浏览器核验网站证书中的域名是否与访问地址一致。
ca|認証局（CA）|Certificate Authority|证书颁发机构|定めた手続きに従って対象を確認し、証明書を発行する主体。|按规则核验主体或域名，并签发数字证书。|机构验证域名控制权后向网站签发证书。
pki|PKI（公開鍵基盤）|Public Key Infrastructure|公钥基础设施|証明書の発行、配布、失効などを管理し、公開鍵への信頼を支える仕組み。|建立和管理对公钥的信任，包括证书颁发、验证和撤销。|企业建立内部体系，统一向员工设备颁发客户端证书。
certificate-chain|証明書チェーン|Certificate Chain|证书链|対象の証明書から中間の発行者をたどり、信頼できる起点までつながる証明書の列。|一组签名关系相连的证书，用于从站点证书追溯到可信根。|浏览器通过中间证书验证网站证书的签发路径。
crl|CRL（証明書失効リスト）|Certificate Revocation List|证书撤销列表|有効期間の途中で無効になった証明書の番号などを、発行者が一覧にしたもの。|证书颁发机构公布的已撤销证书清单。|系统定期更新清单，拒绝已提前作废的证书。
ocsp|OCSP|Online Certificate Status Protocol|在线证书状态协议|特定の証明書について失効したかどうかをオンラインで問い合わせるプロトコル。|可查询某张证书是否已被撤销。|验证程序检查一个仍在有效期内的证书是否已被撤销。
timestamp|タイムスタンプ（電子証明）|Trusted Timestamp|可信时间戳|電子データがある時点までに存在したことを第三者の時刻情報と署名で示す証拠。|为数据在某时刻之前已存在提供可验证的时间证明。|签约双方为电子合同保留可信签署时间证据。
# 不正なプログラムの種類
malware|マルウェア|Malware|恶意软件|情報の窃取や業務の妨害などを目的とする悪意のあるソフトウェアの総称。|为窃取数据、破坏系统等目的设计的软件总称。|终端防护软件隔离被识别为恶意的程序。
virus|コンピュータウイルス|Computer Virus|计算机病毒|別のファイルやプログラムに寄生し、その実行などを契機に複製される不正なコード。|附着在文件或程序上，在宿主运行等条件下感染更多对象。|安全扫描发现旧共享目录中的可疑感染文件。
worm|ワーム|Computer Worm|蠕虫|他のファイルに寄生しなくても動作し、主にネットワーク経由で自己を複製する不正なプログラム。|可独立运行并自行在网络等途径传播的恶意程序。|发现异常传播迹象后，管理员隔离受影响的网段。
trojan|トロイの木馬|Trojan Horse|木马程序|便利なソフトウェアなどを装い、裏で意図しない不正な機能を実行するプログラム。|伪装成有用程序，执行用户未授权的恶意操作。|管理员从可信来源获取工具，避免使用可疑安装包。
ransomware|ランサムウェア|Ransomware|勒索软件|データを暗号化するなどして利用を妨げ、回復や公開回避と引き換えに金銭を要求する不正なソフトウェア。|阻止用户访问数据，或以泄露数据相威胁，进而索取赎金。|企业使用隔离备份恢复受影响的共享文件。
spyware|スパイウェア|Spyware|间谍软件|利用者に気付かれにくい形で行動や個人情報を収集するソフトウェア。|在用户不知情或未同意的情况下监控活动、收集信息。|安全人员清理偷偷收集浏览活动的可疑插件。
keylogger|キーロガー|Keystroke Logger|键盘记录器|キーボードで入力されたキーの情報を記録する仕組み。|记录按键的软硬件，未经许可使用时可能窃取密码等。|安全软件告警某程序正在异常监控键盘输入。
rootkit|ルートキット|Rootkit|隐蔽控制工具集|侵入後に特権や不正な活動を隠すために使われるツール群。|用于隐藏恶意活动或维持高权限控制的工具集合。|管理员从可信恢复介质检查怀疑遭隐藏篡改的主机。
backdoor|バックドア|Backdoor|后门|通常の認証や手続きとは別に、隠れてアクセスするために設けられた入口。|绕过正常访问流程的隐蔽入口。|审计确认不存在厂商遗留的未受控访问入口。
botnet|ボットネット|Botnet|僵尸网络|外部からまとめて制御される多数の感染端末の集まり。|受同一控制体系操纵的一批被感染设备。|运营商发现大量受控设备发出异常流量，并通知用户处理。
# 不正行為と攻撃の見分け方
phishing|フィッシング|Phishing|钓鱼攻击|信頼できる相手を装うメールやサイトで、認証情報などを入力させようとする行為。|冒充可信机构，诱导用户交出密码或支付信息。|收到疑似银行短信后，用银行官方应用核实消息。
spear-phishing|スピアフィッシング|Spear Phishing|鱼叉式钓鱼|標的の個人や組織に合わせた内容を用い、信頼させて情報などを求める行為。|针对特定个人或机构定制内容的钓鱼。|财务人员收到伪装成真实供应商的付款请求后电话核对。
social-engineering|ソーシャルエンジニアリング|Social Engineering|社会工程|人の心理や信頼関係を利用して、情報の開示や不適切な操作を誘う手口。|利用人的信任、紧迫感或疏忽诱导泄密或操作。|有人自称技术支持索要验证码，员工通过官方渠道核实。
shoulder-surfing|ショルダーハッキング|Shoulder Surfing|肩窥|近くから画面や手元をのぞき、入力内容や表示情報を盗み見る行為。|在旁边观察屏幕或键盘来获取敏感信息。|在公共场所输入 PIN 时，用手遮挡键盘。
brute-force|総当たり攻撃|Brute-Force Attack|暴力破解|考えられる候補を広く試し、正しいパスワードなどを見つけようとする行為。|尝试大量候选值来猜测凭据或密钥。|系统通过登录速率限制减缓反复猜测。
dictionary-attack|辞書攻撃|Dictionary Attack|字典攻击|よく使われる単語や既知の候補の一覧を用いて、パスワードなどを推測する行為。|优先猜测常见词和已知常用密码。|新密码设置时，系统拒绝出现在常用密码清单中的值。
credential-stuffing|パスワードリスト攻撃|Credential Stuffing|撞库攻击|他のサービスから漏れたIDとパスワードの組を、別のサービスで試す行為。|用别处泄露的账号密码尝试登录其他网站。|用户为不同网站设置不同密码以降低风险。
dos|DoS攻撃|Denial-of-Service Attack|拒绝服务攻击|対象の処理資源などを圧迫し、正規利用者がサービスを使えないようにする攻撃。|通过耗尽资源等方式阻断正常用户对服务的使用。|监控发现业务服务出现异常排队，启用限流保护。
ddos|DDoS攻撃|Distributed Denial-of-Service Attack|分布式拒绝服务攻击|多数の送信元から一斉に通信などを送り、対象サービスの提供を妨げる攻撃。|从多处同时施加负载，使目标服务无法正常响应。|网站在流量异常时启用运营商的流量清洗服务。
mitm|中間者攻撃|Man-in-the-Middle Attack|中间人攻击|通信の両者の間に介入し、互いに直接通信していると思わせながら盗聴や改変を行う攻撃。|攻击者夹在通信两端冒充对方，窃听或篡改数据。|浏览器显示证书警告时，员工停止提交账号信息。
# Webとネットワークの防御
firewall|ファイアウォール|Firewall|防火墙|定めた通信規則に従い、ネットワークを出入りする通信の通過を制御する仕組み。|根据规则允许或拦截进出网络的流量。|服务器所在网络只允许必要的业务端口对外开放。
waf|WAF|Web Application Firewall|Web 应用防火墙|Webアプリケーション向けの要求を調べ、危険と判断した通信を遮断する防御機能。|检查 Web 应用层流量，阻止符合拦截规则的危险请求。|电商站的防护设备拦截异常网页请求并记录告警。
ids|IDS（侵入検知システム）|Intrusion Detection System|入侵检测系统|通信や端末の動きを監視し、不正の兆候を見つけて通知する仕組み。|监视网络或主机，发现可疑行为后发出告警。|安全团队收到异常连接模式的检测告警。
ips|IPS（侵入防止システム）|Intrusion Prevention System|入侵防御系统|不正と判断した通信などを検知し、自動的に遮断する仕組み。|识别可疑活动后主动采取阻断措施。|设备自动丢弃命中已启用防护规则的网络流量。
dmz|DMZ（非武装地帯）|Demilitarized Zone|隔离区|外部に公開するサーバなどを、内部ネットワークから分けて配置する領域。|在外部网络与内部网络之间设置独立区段，容纳公开服务。|把公开网站与保存员工资料的内部系统分开部署。
vpn|VPN（仮想専用網）|Virtual Private Network|虚拟专用网络|共有ネットワーク上に論理的な専用の通信経路を作る技術。|在共享网络上形成专用的逻辑网络，远程接入常用加密隧道保护数据。|员工在外使用经过验证的加密连接访问公司内网。
zero-trust|ゼロトラスト|Zero Trust|零信任|接続場所などだけで相手を信用せず、資源へのアクセス要求を明示的に評価する考え方。|不因位于内网就自动信任，按身份、设备状态等条件检查访问请求。|办公网内的电脑访问敏感文件时仍须通过设备检查。
dlp|DLP|Data Loss Prevention|数据防泄漏|機密情報の移動や持ち出しを監視し、規則に従って漏えいを防ぐ仕組み。|识别敏感数据并监控其传输，必要时提醒或阻断。|邮件系统发现含未脱敏身份证号的外发文件并阻止发送。
parameterized-query|パラメータ化クエリ|Parameterized Query|参数化查询|命令文の構造と利用者から受け取る値を分けてデータベースに渡す方式。|单独绑定输入值，使其按数据解释而不会改变 SQL 的结构。|登录查询通过数据库接口绑定用户名，而不拼接 SQL 文本。
output-encoding|出力エンコーディング（Web）|Contextual Output Encoding|按上下文进行输出编码|Web画面へ値を出すとき、出力先で制御記号として解釈されない形に変換する対策。|按 HTML 等输出位置正确转换特殊字符，确保普通数据按文本处理。|论坛把用户评论当普通文字显示，避免其被解释为页面标记。
# セキュリティの運用と対応
patch-management|パッチ管理|Patch Management|补丁管理|修正プログラムの把握、適用可否の確認、配布と結果の確認を計画的に行うこと。|系统地跟踪、测试、安装并核验软件更新。|企业先在测试设备安装安全更新，再按计划推广。
hardening|ハードニング|System Hardening|系统加固|不要な機能や権限を減らし、設定を見直して攻撃を受けにくくする作業。|关闭不必要的服务并采用更安全的设置，减少可受攻击的入口。|服务器上线前关闭不用的远程服务。
audit-log|監査ログ|Audit Log|审计日志|誰がいつどの操作を行ったかを後から確認できるように残す記録。|记录主体、时间和操作等信息，便于复查与追责。|审计员核对管理员何时更改了员工的权限。
siem|SIEM|Security Information and Event Management|安全信息与事件管理|複数の機器やシステムのログを集めて関連付け、セキュリティ上の異常を見つける仕組み。|集中收集、关联和分析日志，用于发现安全事件。|安全系统关联登录失败和后续异常登录事件。
soc|SOC|Security Operations Center|安全运营中心|組織のシステムを監視し、警報の分析や検知後の連絡などを担う運用組織。|负责持续监测、分析告警和开展初步处置。|值班分析员看到异常登录后联系相关团队核查。
csirt|CSIRT|Computer Security Incident Response Team|计算机安全事件响应团队|組織内外の連絡を調整し、セキュリティ事故への対応を担うチーム。|协调安全事件的确认、应对和恢复工作。|发生疑似数据泄露时，响应团队联系技术和管理人员。
incident-response|インシデント対応|Incident Response|安全事件响应|セキュリティ上の事故を確認し、拡大防止・復旧・再発防止などを行う一連の活動。|调查并控制安全事件，恢复业务并总结改进。|确认异常后隔离受影响设备，再验证修复和恢复情况。
forensics|デジタルフォレンジックス|Digital Forensics|数字取证|電子的な証拠を保全し、手順を記録しながら原因や事実を調べる活動。|以能追溯过程的方式保存和分析电子证据。|调查人员保存日志副本并记录采集和交接时间。
edr|EDR|Endpoint Detection and Response|端点检测与响应|端末上の活動を記録・分析し、侵害の兆候を検知して隔離などの対応を行う仕組み。|持续分析终端行为，并支持隔离设备等响应措施。|管理员把出现可疑行为的笔记本从网络临时隔离。
honeypot|ハニーポット|Honeypot|蜜罐|攻撃者が近づきそうな模擬資源を用意し、接触を観測する防御用の仕組み。|用可监测的诱饵资源识别可疑活动。|安全团队观察隔离诱饵系统的异常访问，分析威胁趋势。
# Webアプリケーションの安全性
sql-injection|SQLインジェクション|SQL Injection|SQL 注入|利用者の入力がデータベース命令の一部と誤って解釈され、意図しない処理が行われる問題。|应用把不可信输入误当作 SQL 指令的一部分，导致查询含义发生变化。|开发人员审查搜索功能，确保查询使用参数绑定。
xss|クロスサイトスクリプティング（XSS）|Cross-Site Scripting|跨站脚本攻击|Webページに含まれた信頼できない内容が、閲覧者のブラウザでスクリプトとして動作する問題。|浏览器把网页里的不可信内容当作脚本，在当前网站的上下文中执行。|论坛使用安全的文本输出接口展示访客评论。
csrf|クロスサイトリクエストフォージェリ（CSRF）|Cross-Site Request Forgery|跨站请求伪造|ログイン中の利用者のブラウザから、その利用者が意図しない要求を対象サイトに送らせる行為。|诱导已登录用户的浏览器向目标站点发起非本人意愿的请求。|账户网站为修改邮箱的表单检查请求令牌。
path-traversal|ディレクトリトラバーサル|Directory Traversal|目录遍历|入力されたパスを適切に制限しないため、許可したディレクトリ外のファイルにアクセスできる問題。|应用没有将文件路径限制在指定目录，导致其他位置的文件可能被访问。|下载服务从预设文件清单中选择可交付的文件。
open-redirect|オープンリダイレクト|Open Redirect|开放重定向|Webサイトの転送先が適切に制限されず、任意の外部サイトへ誘導できる問題。|网站允许不可信的输入决定跳转目的地，用户可能被引导到外部站点。|登录服务仅允许跳回批准的内部页面。
clickjacking|クリックジャッキング|Clickjacking|点击劫持|見えている画面に別の画面を重ねるなどして、利用者に意図しない場所をクリックさせる行為。|通过遮盖或叠放界面，让用户在不知情的情况下点击其他控件。|银行页面禁止在无关网站的框架中嵌入。
input-validation|入力値検証|Input Validation|输入验证|外部から受け取った値が、許容した型、長さ、形式、範囲などに収まるかを確かめる処理。|检查收到的数据是否符合预定格式和范围。|注册表单在服务端拒绝超出允许范围的年龄。
same-origin-policy|同一オリジンポリシー|Same-Origin Policy|同源策略|Webブラウザが、異なるスキーム、ホストまたはポートの文書どうしの読み取りなどを制限する規則。|浏览器按协议、主机名和端口区分来源，并限制跨来源读取等操作。|一个网页无法任意读取其他站点的页面内容。
csp|CSP（コンテンツセキュリティポリシー）|Content Security Policy|内容安全策略|Webページで読み込めるスクリプトなどの出所を指定し、ブラウザに制限させる仕組み。|网站声明哪些来源的脚本、图片等内容可以加载，浏览器执行相应限制。|站点部署策略，只允许指定来源提供网页脚本。
samesite|SameSite属性|SameSite Cookie Attribute|Cookie 同站属性|異なるサイトから始まった要求に、ブラウザがCookieを付ける条件を指定する属性。|约束浏览器何时在跨站请求中携带 Cookie。|购物网站让会话 Cookie 在多数跨站请求中不被发送。
