# CPUの構成要素
cpu|中央処理装置（CPU）|Central Processing Unit|中央处理器|プログラムの命令を取り出して解釈し、演算や各装置の制御を行う装置。|CPU 是执行程序指令的主要部件，负责运算并协调数据传送。|打开浏览器时，CPU 执行启动和界面处理代码。
alu|算術論理演算装置（ALU）|Arithmetic Logic Unit|算术逻辑单元|加減算や論理積などを行う、プロセッサ内部の演算回路。|ALU 在处理器内部执行整数加减和按位逻辑等基本操作。|表格中的整数求和可由 CPU 的 ALU 完成。
cu|制御装置|Control Unit|控制单元|命令の解読結果に基づき、演算回路や記憶回路の動作を指示する回路。|控制单元根据指令协调取数、运算和保存结果等步骤。|执行加法时，它向运算回路发出相应控制信号。
fpu|浮動小数点演算装置（FPU）|Floating-Point Unit|浮点运算单元|指数部と仮数部を用いる形式の数に対し、専用の数値計算を行う回路。|FPU 处理用浮点格式表示的数值运算。|计算带小数的传感器平均值时可使用浮点运算。
register|レジスタ|Register|寄存器|プロセッサ内部で、演算に使う値や途中結果などを一時的に保持する小容量の記憶回路。|寄存器是 CPU 内部能快速读写的存储位置，可保存指令操作数和状态。|整数相加后，结果先留在目标寄存器中。
program-counter|プログラムカウンタ（PC）|Program Counter|程序计数器|次に取り出す命令のアドレスを保持し、分岐などに応じて値が変わる専用レジスタ。|程序计数器指明下一步要取哪条指令。|程序执行跳转时，程序计数器更新为目标指令的地址。
instruction-register|命令レジスタ（IR）|Instruction Register|指令寄存器|主記憶から取り出した命令を解読するために、命令そのものを保持する専用レジスタ。|指令寄存器保存刚取出的指令，供控制电路分析。|取到一条加法指令后，控制单元从这里识别操作类型。
status-register|状態レジスタ|Status Register|状态寄存器|演算結果がゼロか、桁上がりが起きたかなどの状態をビットで保持する専用レジスタ。|状态寄存器可保存零标志、进位标志等处理器状态。|比较结果为零时，后续条件分支可以据此跳转。
# 命令実行と並列処理
instruction-set|命令セットアーキテクチャ（ISA）|Instruction Set Architecture|指令集架构|プロセッサが実行する命令や、プログラムから見えるレジスタなどを定める仕様。|指令集架构规定软件能使用的机器指令、寄存器等接口。|为某种架构编译的原生程序通常需要兼容该架构的 CPU。
clock-frequency|クロック周波数|Clock Frequency|时钟频率|プロセッサなどの同期回路に供給される周期信号の、1秒当たりの周期数。|时钟频率衡量处理器时钟每秒振荡的次数，常以 GHz 表示。|3 GHz 表示每秒约 30 亿个时钟周期。
instruction-cycle|命令サイクル|Instruction Cycle|指令周期|命令の取出し、解読、実行など、1命令を処理するための一連の流れ。|指令周期描述 CPU 从取出一条指令到完成处理的基本过程。|处理加法指令时，CPU 先取指和解码，再执行加法。
pipeline|パイプライン処理|Pipelining|流水线处理|命令処理を複数の段階に分け、別々の命令の異なる段階を重ねて進める方式。|流水线把指令处理拆成多个阶段，让多条指令的不同阶段同时进行。|CPU 执行前一条指令的同时，可以为后一条指令解码。
superscalar|スーパスカラ|Superscalar Architecture|超标量架构|複数の実行回路を用い、同じクロック周期に独立した複数の命令を発行できる方式。|超标量处理器可在同一周期把多条互不依赖的指令发往不同执行单元。|一条整数加法和一条独立的载入指令可同时发射。
simd|単一命令複数データ（SIMD）|Single Instruction, Multiple Data|单指令多数据|一つの命令で複数のデータ要素に同じ演算を適用する処理方式。|SIMD 用一条指令处理多个数据元素，适合重复进行相同运算。|图像滤镜可以一次处理多个像素。
multicore|マルチコアプロセッサ|Multicore Processor|多核处理器|単一のプロセッサパッケージに、独立して命令を実行できる中核を複数備えた装置。|多核处理器在一颗处理器内提供多个可执行指令的核心。|视频会议时，一个核心处理音频，另一个核心处理画面。
gpu|画像処理装置（GPU）|Graphics Processing Unit|图形处理器|画像の描画など、多数の類似計算を並列に処理することを得意とする装置。|GPU 有大量适合并行运算的执行资源，用于绘图或通用并行计算。|3D 游戏用 GPU 同时处理大量顶点和像素。
# 半導体メモリの種類
ram|ランダムアクセスメモリ（RAM）|Random Access Memory|随机存取存储器|任意のアドレスへ直接アクセスでき、一般に作業用として読み書きされる記憶装置。|RAM 可按地址直接读写，电脑的工作内存通常使用断电会丢失数据的 RAM。|浏览器把打开的页面和处理中间数据放在内存里。
rom|リードオンリーメモリ（ROM）|Read-Only Memory|只读存储器|通常の利用時には書換えを行わず、電源を切っても内容を保持する記憶装置の総称。|ROM 主要用于读取预先写入且需断电保留的数据。|简单设备把固定启动程序放在 ROM 里。
sram|スタティックRAM（SRAM）|Static Random Access Memory|静态随机存取存储器|電源供給中は周期的な再書込みをせず、回路の安定状態によって値を保持する揮発性メモリ。|SRAM 在通电时不需要刷新，速度快，通常成本较高。|处理器的高速缓存通常采用 SRAM。
dram|ダイナミックRAM（DRAM）|Dynamic Random Access Memory|动态随机存取存储器|コンデンサの電荷で値を表し、保持するために定期的なリフレッシュを必要とするメモリ。|DRAM 用电荷表示数据，需要定期刷新，常用作主内存。|电脑的 DDR 内存条主要使用 DRAM 芯片。
mask-rom|マスクROM|Mask Read-Only Memory|掩膜只读存储器|製造時に回路パターンによって内容を決め、その後は書き換えられないメモリ。|掩膜 ROM 的数据在生产芯片时固定，适合大量制造内容相同的设备。|同一型号设备可内置固定的查找表。
prom|PROM|Programmable Read-Only Memory|可编程只读存储器|製造後に利用者が一度だけ内容を書き込める不揮発性メモリ。|典型 PROM 可以在出厂后编程一次，写入后无法擦除。|制造商给小批量设备一次性写入配置。
eprom|EPROM|Erasable Programmable Read-Only Memory|可擦除可编程只读存储器|チップに紫外線を照射して内容を消し、再書込みできる不揮発性メモリ。|典型 EPROM 可通过紫外线擦除，再用编程器写入。|维护旧控制板时，可擦除芯片并烧录更新后的程序。
eeprom|EEPROM|Electrically Erasable Programmable Read-Only Memory|电可擦除可编程只读存储器|電気的に内容を消去して書き直せる、少量の設定保存などに使われる不揮発性メモリ。|EEPROM 能用电信号擦写，适合保存少量需断电保留的设置。|温度计把校准值存入 EEPROM。
flash-memory|フラッシュメモリ|Flash Memory|闪存|一般にまとまった単位で消去し、電源なしでも内容を保持できる半導体メモリ。|闪存是一种可电擦写的非易失存储，通常按块擦除。|数码相机把照片保存在存储卡的闪存里。
# 記憶階層と性能
main-memory|主記憶装置|Main Memory|主存储器|実行中のプログラムや使用中のデータを、プロセッサが参照できる形で保持する装置。|主存储器保存程序运行时使用的指令和数据，现代计算机通常使用 DRAM。|运行绘图软件时，程序和正在编辑的图像占用主存。
secondary-storage|補助記憶装置|Secondary Storage|辅助存储器|電源を切った後も、ファイルやプログラムを長期保存するための記憶装置。|辅助存储器负责长期保存文件，常见设备包括 SSD 和硬盘。|关机后，已保存的照片仍保存在硬盘里。
cache-memory|キャッシュメモリ|Cache Memory|高速缓冲存储器|下位の記憶装置の一部を高速な回路に複製し、平均的なアクセス時間を短くする記憶装置。|高速缓存保存慢速存储器中的一部分数据，让重复访问更快。|CPU 反复读取循环中的变量时可直接命中缓存。
cache-hit|キャッシュヒット|Cache Hit|缓存命中|要求されたデータが高速な一時記憶領域に見つかること。|缓存命中表示所需数据已存在于缓存，可以直接从那里读取。|反复读取同一内存位置时，后续读取可能命中 CPU 缓存。
cache-miss|キャッシュミス|Cache Miss|缓存未命中|要求されたデータが高速な一時記憶領域になく、下位の記憶装置を参照すること。|缓存未命中时，需要从更低一层的存储查找数据，通常耗时更长。|CPU 首次读取不在缓存中的数据时可能访问主内存。
cache-line|キャッシュライン|Cache Line|缓存行|高速な一時記憶領域と下位の記憶装置との間でまとめて転送される固定サイズのデータ単位。|缓存行是 CPU 缓存填充、写回等操作使用的一段连续数据。|读取数组某一元素时，同一缓存行中的邻近元素可能一起载入。
memory-interleaving|メモリインタリーブ|Memory Interleaving|内存交叉存取|連続するアドレスを複数の記憶バンクに分散して割り当て、アクセスを重ねられる方式。|内存交叉存取把相邻地址分布到不同存储体，从而提高并行访问机会。|连续读取数组时，不同存储体可以交替响应请求。
write-through|ライトスルー|Write-Through|直写|高速な一時記憶領域への書込みと合わせて、下位の記憶装置も更新する方式。|直写策略更新缓存时也向下层存储写入，不必等缓存行被替换才写回。|CPU 写入一个值时，缓存更新并向下一层发出写请求。
write-back|ライトバック|Write-Back|写回|まず高速な一時記憶領域だけを更新し、置換時などに変更を下位の記憶装置へ反映する方式。|写回策略可合并多次更新，再在适当时机把数据写入下层。|对同一个缓存行连续写入时，可以在该行被替换时再写出最终内容。
# ドライブと記録方式
hdd|ハードディスクドライブ（HDD）|Hard Disk Drive|机械硬盘|回転する円板の表面を磁化し、磁気ヘッドでデータを読み書きする装置。|机械硬盘通过旋转盘片和移动磁头保存数据，适合大容量存储。|家用台式机可以用大容量 HDD 存放旧照片。
ssd|ソリッドステートドライブ（SSD）|Solid-State Drive|固态硬盘|回転する部品を用いず、主に不揮発性半導体メモリでデータを保存するドライブ。|SSD 通常使用闪存存储数据，没有机械寻道，随机读取往往更快。|把操作系统装在 SSD 上，开机通常更快。
optical-disc|光ディスク|Optical Disc|光盘|レーザー光の反射などの違いを利用してデータを読み取る円盤状の記録媒体。|光盘通过激光读取光学特征，CD、DVD 和 Blu-ray 都属于光盘。|使用光驱播放 DVD 里的影片。
magnetic-tape|磁気テープ|Magnetic Tape|磁带|細長い帯の表面を磁化して記録し、巻き送りながら順番に読み取る媒体。|磁带适合顺序读写大量数据，常用于归档。|机房把每月的历史数据保存到磁带库中。
sector|セクタ|Sector|扇区|ディスクを区切って扱うための単位で、装置の読み書きの指定に使われる領域。|扇区是磁盘设备处理数据的基本分区之一，常见逻辑扇区为 512 字节或 4 KiB。|诊断软件可以报告读不到的磁盘扇区。
track|トラック|Track|磁道|磁気ディスク上で、回転方向に沿って同心円状に設けられる記録領域。|磁道是磁性盘片上按圆周排列的记录带。|硬盘在读相邻区域时，磁头可能停留在同一磁道。
seek-time|シーク時間|Seek Time|寻道时间|磁気ディスクのヘッドを目的の記録位置の半径へ移動させるのにかかる時間。|寻道时间是机械硬盘把磁头移动到目标磁道所用的时间。|散落在不同磁道的小文件会造成频繁寻道。
rotational-latency|回転待ち時間|Rotational Latency|旋转等待时间|磁気ディスクで、目的のセクタが回転してヘッドの下に来るまでの時間。|旋转等待是磁头就位后，等待目标扇区转到磁头下方的时间。|读取某个扇区前，硬盘可能先等盘片转过一段距离。
wear-leveling|ウェアレベリング|Wear Leveling|磨损均衡|不揮発性半導体メモリの消去・書込みが特定のブロックに集中しないよう分散する技術。|磨损均衡分散闪存块的擦写次数，延长设备可使用的时间。|SSD 控制器把频繁更新的数据轮换写到不同块。
# 入出力機器
keyboard|キーボード|Keyboard|键盘|キーの押下によって文字やコマンドをコンピュータに入力する装置。|键盘把按键动作转换成输入信号。|在编辑器里用键盘输入代码。
mouse|マウス|Mouse|鼠标|机などの表面で装置を動かし、画面上のポインタ移動や選択を行う入力装置。|鼠标把手部位移转换成屏幕指针移动，并用按键触发操作。|移动鼠标指针后点击一个菜单项。
touchscreen|タッチスクリーン|Touchscreen|触摸屏|表示面に触れた位置を検出し、表示と位置入力を一体で行う装置。|触摸屏同时显示信息和检测手指或触控笔的位置。|在自助终端上直接点击屏幕选择商品。
scanner|イメージスキャナ|Image Scanner|图像扫描仪|紙などの原稿を光学的に読み取り、デジタル画像として取り込む入力装置。|扫描仪把纸面内容转换成数字图像。|将纸质合同扫描成 PDF 中的图像页面。
barcode-reader|バーコードリーダ|Barcode Reader|条码阅读器|印刷された線や空白のパターンなどを読み取り、商品番号などのデータに変換する装置。|条码阅读器把条码图案解码为商品编号等数据。|收银台扫描商品包装上的条码查找价格。
webcam|ウェブカメラ|Webcam|网络摄像头|映像をリアルタイムに取り込み、コンピュータ上の通話などに供給するカメラ。|网络摄像头把连续画面输入电脑，供视频会议等应用使用。|参加远程会议时打开摄像头传送自己的画面。
inkjet-printer|インクジェットプリンタ|Inkjet Printer|喷墨打印机|ノズルから微小な液体の滴を紙に吹き付けて印刷する出力装置。|喷墨打印机把墨滴喷到纸面形成文字和图像。|使用彩色喷墨机在相纸上打印照片。
laser-printer|レーザプリンタ|Laser Printer|激光打印机|光で感光体に像を作り、粉末の色材を紙に転写して熱などで定着させる出力装置。|激光打印机用感光鼓形成图像，再把碳粉转印并固定到纸上。|办公室用激光打印机连续输出多页合同。
3d-printer|3Dプリンタ|3D Printer|三维打印机|立体データに基づき、材料を層ごとに積み重ねるなどして物体を作る装置。|3D 打印机依据数字模型逐层成形，制造实体物件。|用塑料打印一个外壳原型来验证尺寸。
# 画面と音の仕様
lcd|液晶ディスプレイ（LCD）|Liquid Crystal Display|液晶显示器|液晶層の状態を変えて光の通過量を調整し、画像を表示する装置。|常见液晶屏通过液晶控制背光透过量形成画面。|液晶显示器使用背光照亮屏幕。
oled|有機ELディスプレイ|Organic Light-Emitting Diode Display|有机发光二极管显示器|有機材料で作られた発光素子が画素ごとに光を出して画像を表示する装置。|OLED 屏的像素可自行发光，显示纯黑时可关闭对应像素。|手机的 OLED 屏在显示黑底界面时让黑色像素熄灭。
aspect-ratio|画面のアスペクト比|Display Aspect Ratio|屏幕宽高比|画面の横の長さと縦の長さの関係を、16対9などの比で表した値。|屏幕宽高比描述画面宽度和高度的比例，与屏幕的绝对尺寸无关。|在 16:9 的屏幕上观看 4:3 视频时，保留原比例会在两侧留出空白。
interlaced-scan|インタレース走査|Interlaced Scan|隔行扫描|1画面を奇数行と偶数行に分け、それぞれを異なる時点に伝送または描画する方式。|隔行扫描把画面的奇数行和偶数行分成两场传输或绘制。|播放隔行扫描的旧电视录像时，可先转换成逐行画面。
refresh-rate|リフレッシュレート|Refresh Rate|刷新率|表示装置が画面を書き換える頻度で、通常はヘルツで表す値。|刷新率表示显示器每秒可刷新画面的次数。|在内容和显卡支持的情况下，120 Hz 显示器可更平滑地显示运动。
progressive-scan|プログレッシブ走査|Progressive Scan|逐行扫描|画像の全ての行を順番に一度ずつ処理し、1フレームを作る方式。|逐行扫描在一个帧周期内依次处理完整画面的各行。|1080p 中的 p 指逐行扫描。
dpi|ドット毎インチ（DPI）|Dots Per Inch|每英寸点数|印刷などで、1インチの長さに配置される点の数を表す単位。|DPI 表示输出设备单位长度可放置的墨点或印刷点数量。|比较打印机细节表现时，常查看其 DPI 规格。
pixel-response-time|画素応答時間|Pixel Response Time|像素响应时间|表示装置の画素が、ある明るさや色の状態から別の状態に変わるまでの時間。|像素响应时间衡量显示单元切换到另一状态所需时间，规格应结合测量条件理解。|像素转换较慢的显示器在播放高速运动画面时可能出现拖影。
quantization-bits|量子化ビット数|Quantization Bit Depth|量化位数|音などの信号を離散化するとき、1回分の標本の大きさを表すビット数。|量化位数决定每个采样值能分成多少个幅度级别。|16 位 PCM 音频的每个样本有 65536 个编码级别。
# バスと接続規格
data-bus|データバス|Data Bus|数据总线|プロセッサやメモリなどの間で、命令や処理対象の値そのものを転送する信号線群。|数据总线在部件之间传送实际的指令或数据内容。|从内存读取数字时，返回的数字经数据总线传到处理器。
address-bus|アドレスバス|Address Bus|地址总线|アクセス対象となる記憶位置や入出力先の番号を伝える信号線群。|地址总线用来指明本次要访问的内存地址或设备地址。|CPU 通过地址信号选择要读取的内存位置。

usb|USB|Universal Serial Bus|通用串行总线|周辺機器を接続し、データ転送や給電に利用できる汎用のシリアルインタフェース規格。|USB 支持多种外设连接，可同时提供数据通信和供电。|用 USB 线连接电脑和打印机。
pcie|PCI Express（PCIe）|Peripheral Component Interconnect Express|高速串行扩展总线|コンピュータ内部で拡張機器を接続する、レーンを使った高速のポイントツーポイント規格。|PCIe 用串行通道连接显卡和存储控制器等设备，常见 x1、x4 和 x16 配置。|台式机独立显卡通常插在 PCIe x16 插槽中。
sata|シリアルATA（SATA）|Serial Advanced Technology Attachment|串行 ATA|主に内蔵のハードディスクや光学ドライブとコンピュータをつなぐシリアル接続規格。|SATA 是连接机械硬盘、部分 SSD 和光驱的设备接口。|用 SATA 数据线把一块 2.5 英寸硬盘接到主板。
nvme|NVMe|Non-Volatile Memory Express|非易失性内存高速接口协议|主にPCI Express接続の半導体ストレージに対し、効率よく入出力を要求するための仕様。|NVMe 是适合高速非易失存储的访问协议，常用于通过 PCIe 连接的 SSD。|NVMe SSD 可用多条队列并行接收系统的读写请求。
hdmi|HDMI|High-Definition Multimedia Interface|高清多媒体接口|1本のケーブルでデジタル映像と音声を表示装置などへ送る接続規格。|HDMI 用于传输数字视频和音频，常见于电视、显示器和游戏机。|用一条 HDMI 线把电脑接到带扬声器的电视。
ps2|PS/2ポート|Personal System/2 Port|PS/2 接口|従来のPCでキーボードやマウスを接続する、6ピンの小型丸形端子を使う規格。|PS/2 是传统电脑连接键盘和鼠标的接口，使用 6 针圆形插头。|旧式台式机可用紫色 PS/2 端口连接兼容键盘。
# 組込み装置と信号変換
microcontroller|マイクロコントローラ（MCU）|Microcontroller Unit|微控制器|プロセッサ、メモリ、入出力回路などを一つのチップにまとめ、機器の制御に使う装置。|微控制器集成执行单元、存储和外设接口，适合控制具体设备。|洗衣机用微控制器读取水位并控制电机。

fpga|FPGA|Field-Programmable Gate Array|现场可编程门阵列|製造後に利用者が論理回路の構成を設定し直せる半導体デバイス。|FPGA 可在硬件层面配置逻辑和连接关系，适合验证或加速定制电路。|设计团队先在 FPGA 上验证数字滤波电路。
asic|ASIC|Application-Specific Integrated Circuit|专用集成电路|特定の用途に合わせて回路を設計し、専用の機能を効率よく実行する集積回路。|ASIC 为特定用途设计，能按目标功能优化面积、性能或功耗。|网卡可使用专用芯片完成大量数据包处理。
adc|A/D変換器（ADC）|Analog-to-Digital Converter|模数转换器|連続的に変化する電気信号を測り、数値の列として扱えるようにする回路。|模数转换器把连续的模拟输入转换成计算机可处理的数字值。|录音设备把麦克风电压转换成数字音频样本。
dac|D/A変換器（DAC）|Digital-to-Analog Converter|数模转换器|デジタルの数値を対応する電圧などのアナログ信号に変換する回路。|数模转换器依据数字值输出相应的模拟信号。|播放音乐时把数字音频样本转换成耳机可用的模拟信号。
sensor|センサ|Sensor|传感器|温度や明るさなどの物理量を検出し、処理できる信号として出力する装置。|传感器测量环境或设备的物理状态，再输出对应信号。|自动照明用光线传感器检测环境亮度。
actuator|アクチュエータ|Actuator|执行器|制御信号に従って力や変位などの物理的な動作を起こす装置。|执行器接收控制命令并产生机械动作等实际效果。|自动窗帘用电机执行打开和关闭命令。
pwm|パルス幅変調（PWM）|Pulse Width Modulation|脉宽调制|周期的なパルスのオン時間の割合を変えて、平均的な出力などを調整する方式。|PWM 改变每个周期内信号开启的时间比例，以调节平均输出。|用 PWM 调节 LED 的亮度。
# 基板・電源・冷却
